# 기타 연습 도우미

어쿠스틱 기타 연습 앱 (PWA). 입문~중급.

- **코드**: 코드 사전(근음 12 × 종류 15, 개방·바레 모양), 마이크로 잡아 보기(긁어서 / 한 줄씩), 전환 연습(1분 전환 자동 세기, 박자 맞춰 바꾸기)
- **핑거 → 핑거스타일**: 멜로디 + 엄지 베이스를 함께 치는 연습곡 5곡(작은 별, 환희의 송가, 징글벨, Amazing Grace, Greensleeves) × 4단계(강박 베이스 → 박마다 엄지 핀치 → 채우기 → 트래비스), 멜로디·베이스·채우기 따로 듣기, 따라 치기(멜로디 음 따로 판정)
- **내 곡 핑거스타일 편곡**: M| 멜로디 줄(또는 MusicXML 리드시트) + 코드 → 핑거스타일 탭 자동 편곡 (6단계: … 5 퍼커시브, 6 하모닉스 / 멜로디 자동·옥타브 위 하이 포지션·낮게), 새 곡으로 저장
- **기법 연습장**: 퍼커시브(베이스·몸통 치기 박자), 하모닉스(12·7·5프렛, 누름·뮤트 구별, 울림 시간), 해머온·풀오프(둘째 음 크기)
- **고급 단계**, 변칙 조율(DADGAD·오픈 G 등)에서 코드 자리 자동 찾기, 곡 템포 사다리
- **핑거 → 아르페지오**: 패턴 11개(p-i-m-a, 트래비스, 핀치, 퍼커시브 …)를 코드 진행에 입혀 탭으로 보기·듣기, 따라 치기 채점(박자·음), 템포 사다리
- **내 곡**: ChordPro(`[C]가사`), 코드 줄 + 가사 줄, 마디 줄(`| C . G . |`), ASCII 탭을 붙여 넣어 보기·재생, 카포·조 옮김
- **코드 → 스트럼**: 긁기 패턴 9개 + 내 긁기 만들기, 따라 긁기 채점
- **내 패턴 만들기**: 핑거(칸 × 손가락 표), 긁기(칸 눌러 ↓↑✕)
- **탭 리듬 줄**: 탭 위 `R| q e e …` 로 음 길이를 정확히
- **녹음 비교**: 파형, 두 녹음 A/B 같은 자리로 바꿔 듣기
- **튜너 · 지판**: 튜너(줄 자동 인식, 조율 6가지), 메트로놈, 지판 음 이름 외우기(보고 맞히기 / 마이크로 찾아 치기, 약한 자리 더 자주), 스케일 모양(펜타토닉·블루스·메이저·마이너, 포지션, 한 음씩 따라 치기)
- **오늘**: 할 일, 복습함(약했던 연습을 1·2·4·7·14일 간격으로), 주별 추이·발전 기록

```
npm install
npm run dev        # 개발
npm run phone      # 휴대폰에서 (https)
npm test           # 단위 시험
npm run smoke      # 빌드 + 가짜 마이크로 화면 흐름 시험 (Playwright)
```

main 에 올리면 GitHub Actions 가 시험 → 빌드 → GitHub Pages 배포.
